## Overview

This project is a responsive static website built with pure **HTML, CSS, and JavaScript**.  
It presents Rhythm Entertainments' digital identity with a modern Web3-inspired visual style and interactive media sections.

## Features

- **Premium UI/UX** with neon theme, smooth transitions, and responsive layout
- **Artist roster section** with dynamic rendering from centralized data
- **Music catalog** with genre filters (Punjabi, Haryanvi, Hindi)
- **Global search overlay** for tracks, artists, and genres
- **Integrated YouTube player** with custom floating audio controls
- **Video modal playback** for official music videos
- **SEO-ready metadata** (title, description, canonical URL, Open Graph basics)

## Tech Stack

- **HTML5**
- **CSS3** (custom properties, grid/flex layouts, animations)
- **Vanilla JavaScript (ES6)**
- **YouTube IFrame API**
- **Font Awesome** + **Google Fonts**

## Quick Start

Since this is a static project, no build step is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/varun-0765/Rythm-portfolio.git
   ```
2. Open the project folder.
3. Run `index.html` in your browser.

## Customization

You can easily tailor the website for future releases:

- Update **artist and song data** inside `musicData` in `index.html`
- Replace branding assets (logo, colors, typography)
- Edit external links (YouTube, Instagram, deployment URL)
- Add or remove sections depending on campaign needs
